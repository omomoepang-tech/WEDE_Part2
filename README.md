## Project Overview
• Name: Nova Living Resort  
Nova Living Resort is an owned luxury resort built on the idea that a high-end getaway and a 
family holiday do not have to be different trips. The property combines premium suites, spa, 
dining facilities and kids' area places, so guests of all ages are allowed on the same stay.  
• Mission  
To deliver an unmatched standard of hospitality that strikes a genuine balance between high 
end elegance and practical, family friendly comfort.  
• Vision  
The vision is for the resort to be recognized as the resort of luxury and family travel meet- a 
destination where guests return to for both relaxation and lasting memories with loved ones.  
• Target Audience  
The target audience is for families, couples and even singles between the age (25-60) planning a 
getaway and who want to resort level of comfort, safety and service without having to choose 
between a luxury trip and family trip.

##Project goals and objectives
The website's core purpose is to give Nova Living Resort a professional online presence that 
builds trust with prospective guests and converts interest into completed enquiries and 
bookings. Therefore, the goals should include:  
• Present the resorts story, value of it and its facility clearly to our first time visitors.  
• Generate qualified boking enquiries for suites, spa, dining dates and kiddies and family 
activities.  
• Provide caring and loving respect from the staff and however the resort should   provide 
an easy mobile friendly way for guests to browse services and get in touch.  
• The resort should build a long-term brand credibility through consistent design and 
accurate complete information across every page. 

##Website features and functionality
Vip Suite Stay – overview of suite tier, in room amenities etc.  
• Spa & Wellness Package – treatments on offer and the adults have their own relaxation 
room experience.  
• Fine Dining – dining venues, cuisine style and any family/kids dining options.  
• Family & Kids Activities – supervised activities and facilities that make the resort safe 
and engaging for children.  
The functionality includes a navigation bar linking each page to its correct destination, a grid 
layout for all the services and a header and footer.  
• The technical requirements  
The website will be built using Html, CSS and JavaScript. It will be optimized for google

**Repository:** https://github.com/omomoepang-tech/WEDE_Part2
**Live website:** https://omomoepang-tech.github.io/WEDE_Part2/

### New features
- **Interactive elements:** FAQ accordion (About), tabs and a gallery lightbox (Services), and a modal (Enquiries)
- **Dynamic content:** the services list is built with JavaScript, with search, category filter and sorting
- **Interactive map** on the Contact page
- **Forms:** HTML5 and JavaScript validation with clear error messages on the Enquiries and Contact pages. The Enquiries form shows a cost estimate, and the Contact form compiles the message into an email
- **Footer:** shows today's date, a live clock and an automatic copyright year
- **SEO:** a unique title, meta description and meta keywords on every page, one h1 per page, descriptive image file names and alt text, robots.txt and sitemap.xml
- **Responsive design:** media queries at 1400px, 1199px, 1024px, 768px, 600px and 400px, plus landscape phones

### Technologies
HTML5, CSS3, JavaScript, Leaflet / Google Maps embed, Formspree, Git and GitHub.

### Folder structure
- index.html, about.html, services.html, enquiries.html, contact.html
- css_assets (myfirststyles.css, part3.css)
- js_assets (part3.js)
- _images
- robots.txt, sitemap.xml, README.md

### Deployment
The site is deployed with GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
